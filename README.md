# Bank Transactions EDA
An exploratory data analysis of 50,000 bank transactions, uncovering customer transaction behaviour across transaction types, channels, customer occupation, and location.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## Key Findings
- ATMs dominate debit transactions due to their primary use for cash withdrawals.
- Students lead all occupations in total money movement, driven by a combination of frequent low-value purchases and periodic high-value acquisitions.
- Debit activity drives monthly fluctuations, with dips reflecting post-January spending caution, Easter period cash flow improvements, mid-year saving behaviour, and pre-December holiday saving.
- A city's total transaction amount is determined by a combination of transaction frequency and average transaction amount rather than either metric alone.
